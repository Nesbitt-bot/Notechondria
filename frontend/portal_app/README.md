# frontend/portal_app

Thin Flutter entrypoint package for **Notechondria Portal**.

Current mapping from the legacy single frontend:

- shared code lives in `../shared`
- this app starts the extracted shell on tab index `4`
- this is scaffolding, not a fully isolated runtime yet

Planned ownership:

- editor_app: learner/note editing flows
- planner_app: front/course/activity orchestration for planning
- portal_app: auth/settings/orchestration shell
